# Phân tích dữ liệu khách hàng và dự đoán quyết định gửi tiền tiết kiệm tại ngân hàng

Hệ thống phân tích dữ liệu khách hàng và dự đoán khả năng đăng ký gửi tiền tiết kiệm có kỳ hạn tại ngân hàng thương mại. Hệ thống sử dụng các mô hình học máy để đánh giá khả năng gửi tiền, phân nhóm khách hàng bằng K-Means và ứng dụng SHAP để xác định, giải thích các yếu tố ảnh hưởng đến kết quả dự đoán. Qua đó, cung cấp thông tin giúp ngân hàng hiểu rõ hơn về khách hàng và xây dựng các hoạt động tiếp thị phù hợp.
